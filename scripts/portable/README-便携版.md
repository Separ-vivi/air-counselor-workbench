# 辅导员工作平台 · 便携版

## 快速开始（解压即用）

1. 下载 zip 后**完整解压**到任意目录（不要直接在压缩包里运行）
2. 双击 `启动.bat`
3. 等待提示"服务已就绪"，浏览器会自动打开 http://127.0.0.1:8000

> 本便携包**已内置 Python 运行时和所有依赖**，无需单独安装 Python。
> Windows 10/11 64 位系统可直接运行。如 SmartScreen 提示，点"更多信息"→"仍要运行"。

## 端口

固定使用 `8000` 端口，如被占用请先关闭占用程序。

## 数据位置

- SQLite 数据库: `backend/data/`
- 上传附件: `backend/data/docbox/`
- 设置: `backend/data/settings.json`

## 常见问题

- **闪退/打不开**：确认已完整解压（含 `python/` 目录）；右键以管理员身份运行 `启动.bat`
- **依赖损坏**：双击 `修复依赖.bat` 重新安装
- **端口占用**：修改 `启动.bat` 中 `set DEPLOY_RUN_PORT=8000` 的端口号
